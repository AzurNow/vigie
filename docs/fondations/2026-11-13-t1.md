# Test T1 — détectabilité par strate, exécuté le 2026-11-13

Test décrit dans la passe du [2026-11-09](2026-11-09.md) (« Test T1 ») et dans l'entrée H3 du
[registre](registre.md). Session Claude Code, Opus 5.5 (`claude-opus-5-5`), avec réseau. Agrégats
seulement : aucune institution n'est nommée ; les données téléchargées et les scripts de travail sont
restés hors du dépôt, les scripts sont recopiés en annexe.

## Résultat en cinq lignes

- **Critère de falsification de l'alternative de H3 : non atteint.** Parmi les 13 578 communes de 500 à
  3 500 habitants, **8 à 11 %** ont au moins 10 marchés en 36 mois selon la variante (critère : plus
  de 50 %). L'alternative de l'ADR 0005 tient.
- **Le seuil où la moitié des communes atteint 10 marchés en 36 mois est d'environ 4 000 à 5 500
  habitants** (4 500 sur la mesure de référence), un peu au-dessus des ~3 500 estimés.
- **L'estimation du 2026-11-09 sous-estimait les grandes communes** (10 000–30 000 hab. : 81 à 94
  marchés en moyenne mesurés contre 30 à 61 estimés) et était juste pour les petites.
- **Le nombre d'offres reçues est renseigné pour 78 % des marchés communaux** de la fenêtre récente
  (84 à 87 % pour les marchés notifiés en 2024 et 2025, contre 17 à 27 % de 2020 à 2023).
- **La « rupture de collecte de 2024 » ne vaut pas pour le consolidé communautaire** : 2024 et 2025
  y sont les années les plus fournies, portées par le flux comptable de la DGFiP (`pes_marche_2024`),
  qui fournit 47 % des marchés communaux récents et environ 68 % de ceux des communes de moins de
  3 500 habitants.

## Méthode

- **Un marché** = un `uid` (le fichier a une ligne par marché × titulaire × modification) ; sa date est
  la première `dateNotification` connue ; dates postérieures au 2026-11-13 écartées.
- **Un acheteur** = le SIREN (9 premiers caractères de `acheteur_id`, qui est un SIRET) : les budgets
  annexes d'une commune sont comptés avec elle ; le CCAS, personne morale distincte, ne l'est pas.
- **Fenêtre de référence** : 2023-11-01 → 2026-10-31 (36 mois). Variantes : dédoublonnage inter-sources,
  seuil de 40 000 €, fenêtre mûre 2022-11 → 2025-10, marchés dont `offresRecues` est renseigné ;
  fenêtre ancienne 2020-01 → 2022-12 (format de 2019).
- **Strates** : celles de l'estimation du 2026-11-09 (< 500, 500–2 000, 2 000–3 500, 3 500–10 000,
  10 000–30 000, 30 000–100 000, ≥ 100 000) et les 26 tranches de la DGCL.

## Ce que T1 ne dit pas

- **Exhaustivité** : un acheteur sans marché dans les DECP peut n'avoir passé aucun marché de
  40 000 € ou plus, ou ne pas les avoir publiés. T1 ne les distingue pas ; il n'existe toujours pas de
  référentiel pour le faire (producteur du consolidé, cité au registre).
- **Signal examinable** : 10 marchés en 36 mois est une condition de matière, pas une promesse de
  signal. Ce qui sort réellement pour une institution, c'est le pilote A.
- **Flux comptable** : la qualité propre de `pes_marche_2024` (dates, objets, titulaires) n'est pas
  mesurée ici ; sa part dominante chez les petites communes en fait un point à éprouver pendant le
  pilote A et à documenter dans `docs/11` lors de l'écriture du connecteur `fr/decp`.

### `c1_detectabilite.py`

```python
"""T1 — détectabilité par strate. Agrégats seulement. Usage : c1_detectabilite.py <dossier data>"""
import sys, duckdb
D = sys.argv[1]
con = duckdb.connect()
con.execute(f"CREATE VIEW d AS SELECT * FROM read_parquet('{D}/decp.parquet')")
# une ligne par marché : uid, première notification connue, SIREN acheteur
con.execute("""CREATE TABLE m AS SELECT uid, left(acheteur_id, 9) AS siren, MIN(dateNotification) AS d,
  max(offresRecues) AS offres, any_value(procedure) AS procedure, max(montant) AS montant
  FROM d WHERE dateNotification <= DATE '2026-11-13' GROUP BY uid, left(acheteur_id, 9)""")
print("marchés distincts", con.execute("SELECT COUNT(*), COUNT(DISTINCT uid) FROM m").fetchone())
TR = [0,50,100,200,300,400,500,700,1000,1500,2000,2500,3000,3500,4000,5000,6000,8000,10000,20000,30000,50000,80000,100000,200000,300000]
ST = [0,500,2000,3500,10000,30000,100000]
case = lambda b: "CASE " + " ".join(f"WHEN population >= {x} THEN {x}" for x in reversed(b)) + " END"
con.execute(f"""CREATE TABLE c AS SELECT CAST(SIREN AS VARCHAR) siren, population, {case(TR)} tranche, {case(ST)} strate
  FROM read_csv('{D}/id-communes.csv', all_varchar=false, types={{'SIREN':'VARCHAR'}}) WHERE type = 'COM'""")
def fenetre(a, b, cle, titre, extra=""):
    con.execute(f"""CREATE OR REPLACE TABLE pa AS SELECT siren, COUNT(*) n,
       COUNT(offres) n_offres, SUM(CASE WHEN offres = 1 THEN 1 ELSE 0 END) n_offre_unique
       FROM m WHERE d BETWEEN DATE '{a}' AND DATE '{b}' GROUP BY siren""")
    print(f"\n== {titre} [{a} .. {b}] par {cle}")
    print("cle | communes | pop | >=1 % | >=5 % | >=10 % | >=20 % | med | p90 | moy | marchés avec offres % | >=10 marchés avec offres renseignées %")
    for r in con.execute(f"""SELECT {cle}, COUNT(*), SUM(population),
        ROUND(100.0*COUNT(n)/COUNT(*),1), ROUND(100.0*SUM((n>=5)::INT)/COUNT(*),1), ROUND(100.0*SUM((n>=10)::INT)/COUNT(*),1),
        ROUND(100.0*SUM((n>=20)::INT)/COUNT(*),1), quantile_cont(coalesce(n,0),0.5), quantile_cont(coalesce(n,0),0.9),
        ROUND(AVG(coalesce(n,0)),1), ROUND(100.0*SUM(n_offres)/NULLIF(SUM(n),0),1), ROUND(100.0*SUM((n_offres>=10)::INT)/COUNT(*),1)
        FROM c LEFT JOIN pa USING (siren) {extra} GROUP BY 1 ORDER BY 1""").fetchall():
        print(" | ".join(str(x) for x in r))
fenetre("2023-11-01", "2026-10-31", "strate", "36 mois récents")
fenetre("2023-11-01", "2026-10-31", "tranche", "36 mois récents")
fenetre("2020-01-01", "2022-12-31", "strate", "36 mois anciens (format 2019)")
print("\nCRITÈRE 500–3 500 hab., >=10 marchés / 36 mois récents :", con.execute("""
  SELECT COUNT(*), SUM((coalesce(n,0)>=10)::INT), ROUND(100.0*SUM((coalesce(n,0)>=10)::INT)/COUNT(*),1)
  FROM c LEFT JOIN (SELECT siren, COUNT(*) n FROM m WHERE d BETWEEN DATE '2023-11-01' AND DATE '2026-10-31' GROUP BY siren) USING (siren)
  WHERE population >= 500 AND population < 3500""").fetchone())
for f, lab in [("id-epci.csv","EPCI"),("id-departements.csv","départements"),("id-regions.csv","régions")]:
    r = con.execute(f"""SELECT COUNT(*), ROUND(100.0*COUNT(n)/COUNT(*),1), ROUND(100.0*SUM((n>=10)::INT)/COUNT(*),1),
        ROUND(100.0*SUM((n>=50)::INT)/COUNT(*),1), quantile_cont(coalesce(n,0),0.5), quantile_cont(coalesce(n,0),0.1)
        FROM read_csv('{D}/{f}', types={{'SIREN':'VARCHAR'}}) x LEFT JOIN
        (SELECT siren, COUNT(*) n FROM m WHERE d BETWEEN DATE '2023-11-01' AND DATE '2026-10-31' GROUP BY siren) p ON p.siren = x.SIREN""").fetchone()
    print(lab, "n | >=1 % | >=10 % | >=50 % | médiane | p10 :", r)
print("contrôle, SIREN 'Commune' des DECP absents de la table (communes nouvelles, etc.) :", con.execute("""
  SELECT COUNT(DISTINCT left(acheteur_id,9)) FROM d WHERE acheteur_categorie='Commune' AND left(acheteur_id,9) NOT IN (SELECT siren FROM c)""").fetchone())
```

### `c2_controles.py`

```python
"""T1 — contrôles de robustesse et complétude. Agrégats seulement."""
import sys, duckdb
D = sys.argv[1]
con = duckdb.connect()
con.execute(f"CREATE VIEW d AS SELECT * FROM read_parquet('{D}/decp.parquet')")
con.execute(f"CREATE TABLE c AS SELECT CAST(SIREN AS VARCHAR) siren, population FROM read_csv('{D}/id-communes.csv', types={{'SIREN':'VARCHAR'}}) WHERE type='COM'")
con.execute("""CREATE TABLE m AS SELECT uid, left(acheteur_id,9) siren, MIN(dateNotification) d, max(montant) montant,
  max(offresRecues) offres, any_value(procedure) procedure, any_value(sourceDataset) src, min(titulaire_id) tit
  FROM d WHERE dateNotification <= DATE '2026-11-13' GROUP BY 1,2""")
con.execute("""CREATE TABLE mc AS SELECT m.*, c.population FROM m JOIN c USING (siren)
  WHERE d BETWEEN DATE '2023-11-01' AND DATE '2026-10-31'""")
q = lambda t, s: (print("\n##", t), [print(" | ".join(map(str, r))) for r in con.execute(s).fetchall()])
q("communes, 36 mois : marchés, et doublons probables (même SIREN, date, montant, titulaire, uid différents)", """
  SELECT COUNT(*), COUNT(*) - COUNT(DISTINCT (siren, d, montant, tit)) FROM mc""")
q("doublons probables par strate (% des marchés)", """
  SELECT CASE WHEN population<500 THEN 0 WHEN population<2000 THEN 500 WHEN population<3500 THEN 2000 WHEN population<10000 THEN 3500 ELSE 10000 END s,
   COUNT(*), ROUND(100.0*(COUNT(*) - COUNT(DISTINCT (siren, d, montant, tit)))/COUNT(*),1) FROM mc GROUP BY 1 ORDER BY 1""")
q("source des marchés communaux (36 mois), top 8", "SELECT src, COUNT(*), ROUND(100.0*COUNT(*)/SUM(COUNT(*)) OVER (),1) FROM mc GROUP BY 1 ORDER BY 2 DESC LIMIT 8")
q("source par strate : part PES (comptabilité publique)", """
  SELECT CASE WHEN population<500 THEN 0 WHEN population<2000 THEN 500 WHEN population<3500 THEN 2000 WHEN population<10000 THEN 3500 ELSE 10000 END s,
   ROUND(100.0*SUM((src LIKE 'pes%')::INT)/COUNT(*),1) FROM mc GROUP BY 1 ORDER BY 1""")
q("montants communaux : < 40 k€, nuls/absents, > 1e9", """SELECT ROUND(100.0*SUM((montant<40000)::INT)/COUNT(*),1),
  ROUND(100.0*SUM((montant IS NULL OR montant=0)::INT)/COUNT(*),1), SUM((montant>1e9)::INT) FROM mc""")
q("complétude des champs utiles (communes, 36 mois) : offresRecues, procedure, montant, titulaire ; offre unique % parmi renseignés", """
  SELECT ROUND(100.0*COUNT(offres)/COUNT(*),1), ROUND(100.0*COUNT(procedure)/COUNT(*),1), ROUND(100.0*COUNT(montant)/COUNT(*),1),
  ROUND(100.0*COUNT(tit)/COUNT(*),1), ROUND(100.0*SUM((offres=1)::INT)/COUNT(offres),1) FROM mc""")
q("retard de publication : marchés communaux par mois de notification, 2025-07..2026-10", """
  SELECT strftime(d,'%Y-%m'), COUNT(*) FROM mc WHERE d >= DATE '2025-07-01' GROUP BY 1 ORDER BY 1""")
q("même mois un an plus tôt", "SELECT strftime(d,'%Y-%m'), COUNT(*) FROM mc WHERE d BETWEEN DATE '2024-07-01' AND DATE '2025-06-30' GROUP BY 1 ORDER BY 1")
q("complétude par année (tous acheteurs) : marchés, offresRecues %, procedure %, montant %", """
  SELECT year(d), COUNT(*), ROUND(100.0*COUNT(offres)/COUNT(*),1), ROUND(100.0*COUNT(procedure)/COUNT(*),1), ROUND(100.0*COUNT(montant)/COUNT(*),1)
  FROM m WHERE d >= DATE '2018-01-01' GROUP BY 1 ORDER BY 1""")
```

### `c4_sensibilite.py`

```python
"""T1 — sensibilité : doublons inter-sources, seuil 40 k€, fenêtre mûre. Agrégats seulement."""
import sys, duckdb
D = sys.argv[1]
con = duckdb.connect()
con.execute(f"CREATE VIEW d AS SELECT * FROM read_parquet('{D}/decp.parquet')")
con.execute(f"CREATE TABLE c AS SELECT CAST(SIREN AS VARCHAR) siren, population FROM read_csv('{D}/id-communes.csv', types={{'SIREN':'VARCHAR'}}) WHERE type='COM'")
con.execute("""CREATE TABLE m AS SELECT uid, left(acheteur_id,9) siren, MIN(dateNotification) d, max(montant) montant,
  max(offresRecues) offres, min(titulaire_id) tit FROM d WHERE dateNotification <= DATE '2026-11-13' GROUP BY 1,2""")
con.execute("CREATE TABLE md AS SELECT siren, d, montant, tit, max(offres) offres FROM m GROUP BY ALL")
V = {
 "brut, 2023-11..2026-10": ("m", "2023-11-01", "2026-10-31", ""),
 "dédoublonné, 2023-11..2026-10": ("md", "2023-11-01", "2026-10-31", ""),
 "dédoublonné, >= 40 k€, 2023-11..2026-10": ("md", "2023-11-01", "2026-10-31", "AND montant >= 40000"),
 "dédoublonné, fenêtre mûre 2022-11..2025-10": ("md", "2022-11-01", "2025-10-31", ""),
 "dédoublonné, offresRecues renseigné, 2023-11..2026-10": ("md", "2023-11-01", "2026-10-31", "AND offres IS NOT NULL"),
}
S = "CASE WHEN population<500 THEN '0 <500' WHEN population<2000 THEN '1 500-2000' WHEN population<3500 THEN '2 2000-3500' WHEN population<10000 THEN '3 3500-10000' WHEN population<30000 THEN '4 10000-30000' WHEN population<100000 THEN '5 30000-100000' ELSE '6 >=100000' END"
for lab, (t, a, b, w) in V.items():
    con.execute(f"CREATE OR REPLACE TABLE pa AS SELECT siren, COUNT(*) n FROM {t} WHERE d BETWEEN DATE '{a}' AND DATE '{b}' {w} GROUP BY 1")
    print(f"\n## {lab} — strate | communes | >=1 % | >=10 % | médiane | moyenne")
    for r in con.execute(f"""SELECT {S}, COUNT(*), ROUND(100.0*COUNT(n)/COUNT(*),1), ROUND(100.0*SUM((n>=10)::INT)/COUNT(*),1),
        quantile_cont(coalesce(n,0),0.5), ROUND(AVG(coalesce(n,0)),1) FROM c LEFT JOIN pa USING (siren) GROUP BY 1 ORDER BY 1""").fetchall():
        print(" | ".join(map(str, r)))
    print("CRITÈRE 500-3500 >=10 :", con.execute("""SELECT ROUND(100.0*SUM((coalesce(n,0)>=10)::INT)/COUNT(*),1)
        FROM c LEFT JOIN pa USING (siren) WHERE population>=500 AND population<3500""").fetchone()[0], "%",
        "| seuil de population où la moitié des communes atteint 10 :",
        con.execute("""SELECT MIN(t) FROM (SELECT (population//500)*500 t, AVG((coalesce(n,0)>=10)::INT) p
          FROM c LEFT JOIN pa USING (siren) WHERE population < 20000 GROUP BY 1) WHERE p >= 0.5""").fetchone()[0])
```
