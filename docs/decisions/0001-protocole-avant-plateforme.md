# ADR 0001 — Protocole avant plateforme

Date : 2026-11-07 · Statut : accepté

## Contexte
Un particulier, sans organisation, veut l'impact le plus large possible. Une plateforme centralisée exige hébergement, financement, exposition juridique, et finit capturée ou éteinte.

## Décision
Vigie est un protocole (playbook, connecteur, chaîne de preuve) plus une implémentation de référence locale. Pas de serveur. Le commons (playbooks, connecteurs, catalogue) est le cœur de la valeur.

## Conséquences
Dispersion par copie ; pas de coûts fixes ; pas de point de capture ; mais pas de vue agrégée nationale centralisée (les résumés de strates publiés dans le dépôt en tiennent lieu).
